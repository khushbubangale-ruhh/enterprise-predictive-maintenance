# Enterprise Predictive Maintenance & Equipment Failure Prediction

A complete portfolio **prototype** for Data Scientist and AI/ML Engineer roles. It uses the UCI AI4I 2020 **synthetic** dataset (10,000 rows) to predict the *current-row* machine failure label. **Not a real-world, forward-in-time early warning system.** No actual factory validation has been performed.

## Included
- Official dataset downloader; exploratory Streamlit dashboard
- Leakage-aware feature engineering (never use TWF/HDF/PWF/OSF/RNF or identifiers as inputs)
- Stratified train/validation/test (60/20/20), preprocessing fitted on training data only
- Three models: balanced Logistic Regression, Random Forest, HistGradientBoosting
- Validation average precision for model selection; validation F1 for threshold; untouched test evaluation
- FastAPI `/health`, `/predict`; Streamlit prediction UI
- Pytest tests; GitHub Actions CI

## Windows VS Code quick start (Python 3.11)
```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe download_data.py
.venv\Scripts\python.exe -m src.train
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m streamlit run app.py
```

## API (second terminal)
```powershell
.venv\Scripts\python.exe -m uvicorn api:app --reload
```
Then visit `http://127.0.0.1:8000/docs` to try POST /predict.

## Dataset source and attribution
UCI Machine Learning Repository: **AI4I 2020 Predictive Maintenance Dataset**, DOI: https://doi.org/10.24432/C5HS5C , license CC BY 4.0. The script downloads the original ZIP from UCI. If the download is unavailable, manually obtain `ai4i2020.csv` from https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset and put it in `data/`.

## Responsible interpretation
The label is generated from synthetic failure rules and indicates failure at the recorded observation, not future failure time. Scores may look optimistic due to engineered physical features matching synthetic rules. Do not deploy to real equipment or claim measured cost savings. Dataset and trained artifacts are not bundled; run download/training yourself. `joblib.load` must only load trusted local model files.

## Azure deployment notes
This is **not deployed**. For Streamlit on Azure Linux App Service, use startup command:
`python -m streamlit run app.py --server.address 0.0.0.0 --server.port 8000 --server.headless true`
Deploying requires a model artifact generated by training (not committed by default). Free-tier resources may have CPU/RAM constraints. CI only runs tests; Azure deployment workflow and credentials must be configured separately.

## Further improvements
SHAP explainability, SQL analysis, drift monitoring, hyperparameter tuning, stronger temporal/asset-wise validation on real machine data, and automated Azure deployment are **not implemented** in this package.
